# Одно особенное свидание

Готовый интерактивный сайт для Виктории. PuppenHaus, Новосибирск, 17 октября 2026 года, 18:00 по Новосибирску (UTC+7).

Четыре экрана, адаптивная композиция, работа с клавиатуры, поддержка уменьшения движения, обратный отсчёт, скачивание календарного события. Без сборки, внешних библиотек, фотографий, сервисов и API-ключей. Согласие показывается только на устройстве девушки; уведомление автору не отправляется.

## Посмотреть до публикации

Распакуйте архив и откройте `index.html` в браузере компьютера. Для телефона удобнее сначала опубликовать сайт по инструкции ниже. Предпросмотр HTML в приложении файлов на iPhone может не выполнять JavaScript: проверяйте опубликованную ссылку в Safari.

## Новый репозиторий и GitHub Pages

1. Откройте https://github.com/new и войдите в свой аккаунт.
2. Назовите репозиторий `victoria-date`. Выберите **Public** — для бесплатного GitHub Pages нужен публичный репозиторий. Нажмите **Create repository**.
3. На странице пустого репозитория нажмите **uploading an existing file**. Если репозиторий уже содержит README, используйте **Add file → Upload files**.
4. Перетащите `index.html` и `README.md` из распакованного архива. Файлы должны быть непосредственно в корне репозитория, а не внутри папки `victoria-date`. Не загружайте ZIP вместо файлов.
5. Нажмите **Commit changes**. Для этого сайта дополнительных команд и установки зависимостей не требуется.
6. Перейдите в **Settings → Pages**.
7. В **Build and deployment → Source** выберите **Deploy from a branch**.
8. В **Branch** выберите **main**, рядом **/(root)**, затем **Save**.
9. Дождитесь завершения публикации. Если ссылка ещё не появилась, обновите страницу Pages. Результат обычно доступен по адресу `https://ВАШ-ЛОГИН.github.io/victoria-date/`.
10. Откройте фактическую ссылку из Settings → Pages на телефоне. Пройдите четыре экрана; проверьте дату, время и добавление календарного файла.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Изменить приглашение

В начале JavaScript, после `<script>`, расположен объект `CONFIG`:

```js
const CONFIG = {
  name: 'Виктория',
  date: '2026-10-17',
  time: '18:00',
  timezone: 'Asia/Novosibirsk',
  timezoneLabel: 'По Новосибирску · UTC+7',
  photo: '',
  dressCode: 'Твой самый красивый образ',
  place: 'PuppenHaus',
  city: 'Новосибирск',
  durationMinutes: 120
};
```

Дата должна быть в формате `YYYY-MM-DD`, время — `HH:mm`. `timezone` — название IANA, например `Asia/Novosibirsk`. Таймер учитывает этот пояс независимо от часового пояса телефона. `timezoneLabel` — подпись для посетителя: при смене пояса измените и её. Продолжительность для календаря по умолчанию — 2 часа, это техническая настройка, а не время бронирования.

Фотография не нужна. Чтобы всё-таки добавить её, загрузите `photo.jpg` рядом с `index.html` и замените `photo: ''` на `photo: './photo.jpg'`. При ошибке загрузки остаётся карточка «Я.».

Тексты истории находятся в HTML внутри четырёх `<section class="scene">`. После редактирования на GitHub нажмите **Commit changes**: Pages обновится автоматически. Если меняете данные, обновите также текст внутри `<noscript>` — запасное приглашение при отключённом JavaScript.

## Календарь

Кнопка скачивает `our-date.ics`. Время начала записывается в UTC: 17 октября 2026, 11:00 UTC = 18:00 в Новосибирске. Календарь сам покажет время в своём часовом поясе. Подтвердите импорт события в вашем календаре. Работа импорта зависит от браузера и установленного календарного приложения; на iPhone можно попробовать открыть скачанный файл через «Файлы» или импортировать его на компьютере в синхронизируемый календарь.

## QR-код бесплатно

Создавайте QR только после публикации, используя ссылку на сайт из Pages, а не ссылку на репозиторий.

В Chrome на компьютере откройте опубликованный сайт. В меню браузера найдите **Транслировать, сохранить и поделиться → Создать QR-код** (название пункта зависит от версии). Скачайте изображение. Если такого пункта нет, используйте любой бесплатный генератор обычного статического QR-кода: вставьте HTTPS-ссылку, выберите PNG или SVG, скачайте. Не выбирайте динамическую ссылку с подпиской.

Перед печатью просканируйте код камерой телефона и убедитесь, что открывается сайт. Печатайте чёрный код на белом фоне, размером хотя бы 3 × 3 см, с белым полем вокруг. Проверяйте также распечатанный экземпляр.

## Физическое приглашение

Кремовая плотная бумага, маленький бордовый конверт, QR в центре и две строки:

**«Тебе пришло кое-что личное.»**

*«Это не доставка. Но вечер обещает быть вкусным.»*

Можно оставить у её чашки или положить в книгу с маленькой закладкой. Имя ресторана на бумаге не пишите: пусть его раскроет история.

## Проверки и ограничения

Проверены JavaScript-переходы, единственный активный экран, согласие, возможность подумать, границы таймера, преобразование UTC+7, экранирование и переносы календарного файла. Внешние запросы для работы сайта не нужны. Поддержка `prefers-reduced-motion` встроена.

В этой среде не выполнялась визуальная проверка в браузере или на настоящем iPhone. После публикации рекомендуется один полный проход в Safari, включая открытие календарного файла. Сайт не бронирует ресторан.
